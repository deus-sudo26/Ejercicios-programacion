# Lista de cotejo — Sistema de gestión de Pokémon

**Programación I — Seguimiento de funciones**


## 1. Visualización

- [x] **`mostrar_cabecera()`** — Muestra los títulos de las columnas.
- [x] **`mostrar_un_pokemon()`** — Muestra los datos de un Pokémon.
- [x] **`mostrar_pokemones()`** — Recorre y muestra la colección completa.

## 2. Cálculo de niveles

- [x] **`calcular_promedio()`** — Calcula y devuelve el promedio de una lista de puntajes.
- [x] **`calcular_nivel()`** — Determina el nivel a partir del promedio.
- [x] **`asignar_nivel()`** — Calcula y asigna los niveles de todos los Pokémon.

## 3. Búsquedas

- [x] **`buscar_por_nombre()`** — Devuelve el índice del Pokémon o `-1`.
- [x] **`mostrar_pokemones_tipo()`** — Muestra los Pokémon del tipo solicitado.
- [x] **`mostrar_pokemones_nivel()`** — Muestra los Pokémon del nivel solicitado.
- [ ] **`buscar_por_rango_ataque()`** — Muestra Pokémon dentro de un rango de ataque.
- [x] **`buscar_por_tipo_y_nivel()`** — Muestra Pokémon que cumplen ambas condiciones.
- [x] *`buscar_mayor_ataque()`** — muestra Pokémon con un rango de  mayor ataque.
- [ ] **`buscar_menor_salud()`** — muestra Pokémon con menor salud.

## 4. Estadísticas

- [x] **`contar_pokemones_por_tipo()`** — Devuelve los contadores correspondientes a cada tipo.
- [ ] **`mostrar_cantidad_por_tipo()`** — Muestra las cantidades por tipo.
- [ ] **`mostrar_porcentajes_por_tipo()`** — Calcula y muestra los porcentajes por tipo.
- [ ] **`mostrar_cantidad_por_nivel()`** — Cuenta los Pokémon de cada nivel.
- [ ] **`tipo_predominante()`** — Identifica el tipo con mayor cantidad de Pokémon.
- [ ] **`promedio_ataque_por_tipo()`** — Calcula el promedio de ataque de un tipo.

## 5. Carga de Pokémon

- [ ] **`cargar_pokemon()`** — Solicita los datos, calcula el nivel y agrega el Pokémon a las seis listas. Sin validaciones.

## 6. Ordenamiento

- [ ] **`swap()`** — Intercambia dos elementos de una lista.
- [ ] **`ordenar_por_nivel()`** — Ordena por nivel descendente mediante burbujeo tradicional, manteniendo sincronizadas las listas.

## 7. Integración

- [ ] **`mostrar_menu()`** — Presenta las opciones y devuelve la selección.
- [ ] **`main()`** — Coordina el menú y las llamadas a las funciones mediante `while` y `match`.
